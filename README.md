# 💰 Transaction Management System

This is a work-in-progress full-stack application for managing financial transactions.  
The main goal of this project is not only functionality, but building a **production-quality development workflow** with a focus on testing, CI/CD, and maintainable architecture.

---

## 🚧 Project Status

The project is currently in active development.

At the moment:
- CRUD functionality for transactions is implemented
- Basic frontend and backend integration is working
- Backend development environment is containerized with Docker

Next steps:
- Add frontend testing (unit + integration)
- Improve backend test coverage
- Extend CI/CD pipeline
- Continue improving architecture and validation

---

## 🧠 Tech Stack

### Frontend
- React (Vite)
- TypeScript
- TanStack Table
- Form validation (TanStack Form / custom validation)

### Backend
- FastAPI
- SQLModel (ORM)
- PostgreSQL

### Dev & Tooling
- Docker (development environment)
- Git hooks (linting / formatting)
- ESLint / Black
- Focus on CI/CD readiness

---

## 🎯 Project Goal

The goal of this project is to simulate a real-world production environment by focusing on:

- Clean architecture
- Testing strategy (frontend + backend)
- Automated quality checks
- CI/CD pipeline integration
  
## 📌 Current Features
- Create, read, update, delete transactions
- Interactive transaction table built with TanStack Table
- Backend API with FastAPI
- PostgreSQL database integration
